# タスク管理

**位置づけ**: タスク管理ファイル
**責務**: 未策定、未改訂、未実装タスクの管理
**ステータス**: 運用中

---

## 1. 基本方針

本書は、Adlaire Git Repository の今後の作業対象を管理するタスク管理ファイルである。

本書は、廃止した旧計画ファイルおよび旧候補リストファイルの後継として、未策定、未改訂、未実装の作業だけを管理する。

本書は仕様書ではなく、実装承認でもない。仕様判断は3類マスター仕様書を正本とし、作業承認はユーザーの明示承認を正とする。

作業者は、`AGENTS.md`、`docs/DOCUMENT_INDEX.md`、2類ポリシー、3類マスター仕様書を読んだ後、本書を確認し、該当タスクに基づいて作業対象を特定する。

---

## 2. タスク分類

タスクは以下の2分類で管理する。

| 分類 | 役割 |
|---|---|
| 策定タスク | 未策定または未改訂のルール、ポリシー、仕様、運用条件、検証条件を整理する |
| 実装タスク | 3類マスター仕様書と承認済み方針に基づき、未実装のソースコード、検証、運用導線を実装する |

策定タスクが未完了で仕様または方針が不明確な場合、該当する実装タスクへ進んではならない。

---

## 3. 完了タスクの扱い

完了したタスクは、本書から削除する。

完了履歴は、本書に残さず、Git commit、Pull Request、tag、release notes、必要な仕様書改訂で確認する。

完了タスクを履歴目的で本書へ残してはならない。
