# デプロイポリシー

**対象**: `{PROJECT_NAME}`
**位置づけ**: 2類責務別ポリシー
**責務**: デプロイ、運用基盤、環境管理、公開経路

---

## 1. 個別具体化必須項目

- 標準運用基盤
- 対象環境
- 環境変数
- 配置先
- deploy 手順
- rollback 手順
- 監視
- 障害対応

## 2. 共通デプロイ制約

Docker は、開発、検証、本番、デプロイ、調査、一時確認、補助用途を含む全用途で例外なく採用禁止とする。

標準デプロイ方式は、各プロジェクトの技術要件ポリシーに従い、Docker に依存しない構成として定義する。

## 3. 承認

デプロイ先、運用基盤、公開経路、rollback 方針は、プロジェクトの承認工程に従って決定する。
