# バージョンポリシー

**対象**: `{PROJECT_NAME}`
**位置づけ**: 2類責務別ポリシー
**責務**: バージョン表記、更新条件、リリース系列

---

## 1. 共通方針

バージョン表記、更新条件、リリース系列は AdlaireGroup 共通方針として扱う。

各プロジェクトは、共通方針を破らない範囲でフェーズ、マイルストーン、リリース系列との対応などの固有値を具体化する。

## 2. 個別具体化必須項目

- バージョン形式
- Major / Minor / Patch 等の意味
- 安定版前の扱い
- リリース系列
- フェーズまたはマイルストーンとの対応
- リセット可否
- 更新手順

## 3. 承認

バージョン形式、更新条件、リリース系列の変更は、プロジェクトの承認工程に従って決定する。
