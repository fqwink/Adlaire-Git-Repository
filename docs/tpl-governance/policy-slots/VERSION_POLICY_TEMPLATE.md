# バージョンポリシー

**対象**: `{PROJECT_NAME}`
**位置づけ**: 2類責務別ポリシー
**責務**: 開発版バージョン、安定版バージョン、累積方式、リセット禁止

---

## 1. 共通方針

バージョン表記、更新条件、リリース系列は AdlaireGroup 共通方針として扱う。

AdlaireGroup 関連プロジェクト、プロダクトは、原則として開発版バージョンと安定版バージョンを分離する。

開発版バージョンは `v.0.N` とし、`N` は開発版の累積変更番号とする。

安定版バージョンは `v.X.Y` とし、`X` は安定版リリースの通し番号、`Y` は切り出し時点の開発版 `N` とする。

重大度、破壊的変更、軽微な修正、機能追加、バグ修正、ドキュメント改訂などの変更種別によって桁や増分を使い分けてはならない。

バージョン番号は、いかなる理由があってもリセット、巻き戻し、1からの数え直しをしてはならない。

各プロジェクトは、共通方針を破らない範囲でフェーズ、マイルストーン、リリース系列との対応などの固有値を具体化する。

## 2. 個別具体化必須項目

- バージョン形式
- 開発版バージョンの `N` の意味
- 安定版バージョンの `X` と `Y` の意味
- 安定版前の扱い
- リリース系列
- フェーズまたはマイルストーンとの対応
- リセット可否
- 更新手順

## 3. 承認

バージョン形式、更新条件、リリース系列の変更は、プロジェクトの承認工程に従って決定する。
