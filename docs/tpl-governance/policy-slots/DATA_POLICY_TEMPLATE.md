# データポリシー

**対象**: `{PROJECT_NAME}`
**位置づけ**: 2類責務別ポリシー
**責務**: データ保存、移行、削除、バックアップ、復旧

---

## 1. 共通方針

データ保存、移行、削除、バックアップ、復旧は AdlaireGroup 共通方針として扱う。

各プロジェクトは、共通方針を破らない範囲で保存対象、保存先、保持期間、復旧手順などの固有値を具体化する。

## 2. 個別具体化必須項目

- 保存対象データ
- 個人情報の扱い
- データ所在
- backup / restore
- migration
- export / import
- retention
- 削除方針

## 3. 承認

データ保存、移行、削除、バックアップ、復旧に関する方針変更は、プロジェクトの承認工程に従って決定する。
