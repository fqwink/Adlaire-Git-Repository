# セキュリティポリシー

**対象**: `{PROJECT_NAME}`
**位置づけ**: 2類責務別ポリシー
**責務**: セキュリティ、認証、認可、secret 管理、脆弱性対応

---

## 1. 共通方針

セキュリティ、認証、認可、secret 管理、脆弱性対応は AdlaireGroup 共通方針として扱う。

各プロジェクトは、共通方針を破らない範囲で認証対象、権限モデル、secret 保存先、監査対象などの固有値を具体化する。

## 2. 個別具体化必須項目

- 認証方針
- 認可方針
- secret 管理
- ログ方針
- 入力検証
- 脆弱性対応
- セキュリティレビュー条件
- インシデント対応

## 3. 承認

セキュリティ方針、認証方式、secret 管理、脆弱性対応手順の変更は、プロジェクトの承認工程に従って決定する。
