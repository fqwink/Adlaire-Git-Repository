# ライセンスポリシー

**対象**: `{PROJECT_NAME}`
**位置づけ**: 2類責務別ポリシー
**責務**: ライセンス、権利帰属、配布条件、外部公開

---

## 1. 共通方針

ライセンス、権利帰属、配布条件、外部公開は AdlaireGroup 共通方針として扱う。

各プロジェクトは、共通方針を破らない範囲で権利者、公開可否、配布条件などの固有値を具体化する。

## 2. 個別具体化必須項目

- プロジェクトライセンス
- 権利帰属
- 外部公開可否
- 再配布可否
- 外部ライブラリの許容ライセンス
- ライセンス変更手順

## 3. 承認

ライセンス、公開範囲、配布条件、外部ライブラリ許容条件は、プロジェクトの承認工程に従って決定する。
