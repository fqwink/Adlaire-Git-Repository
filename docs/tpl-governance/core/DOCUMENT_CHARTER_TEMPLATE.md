# ドキュメント憲章

**対象**: `{PROJECT_NAME}`
**位置づけ**: 2類ドキュメント憲章
**責務**: ドキュメント体系、責務境界、改訂単位

---

## 1. 基本方針

本憲章は、`{PROJECT_NAME}` におけるドキュメント体系、責務境界、改訂単位の扱いを定義する。

`AGENTS.md` は1類ルールブックであり、絶対原則、禁止事項、優先順位、承認義務、作業手順を定義する。

2類ポリシーは、`AGENTS.md` に従う下位文書として、責務別方針、判定条件、運用手順を定義する。

3類マスター仕様書は、仕様の正本である。

`docs/DOCUMENT_INDEX.md` は参照索引であり、正本ではない。

---

## 2. 読了義務

すべての作業では、必ず最初に `AGENTS.md` を読む。

その後、`docs/DOCUMENT_INDEX.md` を索引として、作業に必要な2類ポリシー、3類マスター仕様書、計画文書を読む。

未読、部分読了、過去に読んだ記憶、前回作業時の要約だけを根拠に、読了義務を満たしたと扱ってはならない。

---

## 3. 責務境界

1類、2類、3類、計画文書、利用者向け文書の責務を混同してはならない。

責務が混同されている場合は、内容の責務を判定し、該当する正本へ移して整合させる。

---

## 4. 整合性確認

ドキュメント整合性は、1類ルールブック、2類ポリシー、3類マスター仕様書、計画文書、README、実装、テスト、検証導線、バージョン表記、Pull Request 説明を含む全体へ適用する。

矛盾が残る場合は、作業完了として扱ってはならない。
