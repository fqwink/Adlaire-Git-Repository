# Adlaire Git Repository v.1.8 Release Notes

**リリース種別**: 初回安定版リリース
**対象フェーズ**: Phase 7
**リリース日**: 2026-08-21
**ライセンス**: クローズドライセンス

---

## 概要

`v.1.8` は、Adlaire Git Repository の初回安定版リリースである。

本リリースは、Phase 6 までの成果と Phase 7 の安定版リリース判定に基づき、セルフホスト型 Git ホスティング基盤としての基本機能、開発支援機能、組織運用機能、内製 Deno Module Registry 最小機能、主要 workflow、ドキュメント体系の整合を確認したうえで公開する。

---

## 主な内容

- Git clone / fetch / pull / push の基本操作
- ユーザー登録、HTTP Basic Auth、Personal Access Token
- Repository CRUD、visibility、権限確認
- Pull Request、Code Review、Issue、Wiki、Webhook、Release 基本機能
- Organizations、Teams、Projects の最小運用
- Adlaire 内製 Deno Module Registry 最小実装
- SQLite 標準データベースと Database Gateway / driver 境界
- Deno single binary 実行環境
- Web UI の Phase 7 / `v.1.8` 表示
- Phase 6 で確認された既知バグの修正と再発防止テスト

---

## 検証

標準検証は `tools/check-adlaire-git-repository.sh` を使用する。

検証対象は以下を含む。

- `deno fmt --check`
- `deno lint`
- `deno test`
- `deno compile`
- 主要 workflow 統合テスト
- Phase 7 の表示契約
- Phase 6 既知バグ再発防止テスト

---

## 既知制約

- 本プロジェクトはクローズドライセンスである。
- 標準運用基盤は self-host / VPS / 専用サーバーである。
- Docker は現行方針として本番サーバ運用、デプロイ、運用基盤の標準方式である。
- Node.js runtime、npm ecosystem、`npm:` specifier、`package.json`、`node_modules` 前提構成は採用禁止である。
- UI は GitHub 互換対象外であり、本プロジェクト独自 UI である。
- libSQL は将来移行候補であり、本リリースでは SQLite を標準データベースとする。
- Deno Deploy、Turso Cloud、その他 libSQL 系クラウドDBサービスは標準採用しない。

---

## 成果物

GitHub Releases に以下を配置する。

- `adlaire-git-repo-v1.8-aarch64-unknown-linux-gnu`
- `adlaire-git-repo-v1.8-x86_64-unknown-linux-gnu`
- `v1.8_MANIFEST.md`
- `v1.8_CHECKSUMS.txt`
- `v1.8_RELEASE_NOTES.md`

Linux binary は ARM64 と x86_64 の2種類を標準成果物とする。VPS デプロイ時は `uname -m` で対象アーキテクチャを確認し、対応する binary を選択する。

---

## Upgrade / Restore 前提

- `dataDir` 配下の SQLite database を事前バックアップする。
- bare repository 保存領域を事前バックアップする。
- 設定ファイル、環境変数、配布 binary を復旧可能な形で管理する。
- 起動後に `/health`、トップページ、Repository 一覧、主要 API workflow を確認する。
