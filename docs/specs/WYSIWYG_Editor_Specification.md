# Adlaire ブロックベース WYSIWYG エディター仕様書

**位置づけ**: 3類マスター仕様書
**対象**: Adlaire Git Repository で利用するブロックベース WYSIWYG エディター
**実装言語**: TypeScript
**ランタイム方針**: Deno のみ
**出力形式**: JSON
**ライセンス**: クローズドライセンス
**文書バージョン**: v.0.1
**ステータス**: 設計整理中・実装時期未定

---

## 1. 目的

本仕様書は、Adlaire Git Repository で将来採用候補となるブロックベース WYSIWYG エディターの仕様候補を定義する。

本エディターの実装時期、採用Phase、連携範囲は未定である。README、Wiki、Issue、Pull Request、内部ドキュメント編集へ連携するかどうかは、マスター開発計画とユーザー承認に基づいて別途決定する。

エディターは、利用者が視覚的に編集した内容をブロック単位の JSON として保存し、必要に応じて HTML 表示へ変換できることを目的とする。

---

## 2. 上位ルールとの整合

本エディターは、`AGENTS.md` および2類ドキュメント群に従う。

- Node.js ランタイムは採用しない。
- npm パッケージ公開を前提にしない。
- webpack、jest 等の Node.js 前提ツールへ依存しない。
- 外部フレームワークは採用しない。
- Deno 標準ライブラリを最優先候補とする。ただし、個別モジュールの採用はユーザー承認を必須とする。
- JSR レジストリの公開ライブラリは採用可能とする。ただし、ユーザー承認を得るまで採用しない。
- JSR へ公開する場合は、WYSIWYG エディターを公開可能なオープンソースコードとして扱うことを前提とする。
- WYSIWYG エディターがクローズドライセンス、内部専用、非公開資産である場合は、JSR へ公開しない。
- クローズド配布が必要な場合は、短期的には Private Git + Deno import、Deno workspace、vendor 管理を候補とし、中長期的には Adlaire 内製 Deno Module Registry を目標とする。
- 外部ライブラリが必要な場合は、`docs/policies/TECHNICAL_REQUIREMENTS_POLICY.md` に従い、例外採用としてユーザー承認を得る。
- 保存形式、表示形式、セキュリティ要件は3類マスター仕様書に明記する。
- 実装時期、採用Phase、連携範囲はマスター開発計画で明記し、ユーザー承認を得るまで未定とする。

## 3. 基本方針

- ブロック単位でコンテンツを管理する。
- 保存形式は JSON とする。
- 表示時は JSON から HTML へ変換する。
- TypeScript で実装する。
- TypeScript は 6系の最新安定版を採用方針とする。
- Deno ランタイムのみで検証・実行する。
- XSS 対策、URL 検証、JSON 検証を必須とする。
- README や Wiki の表示機能と安全に連携する。

## 4. コンセプト

```text
ユーザー入力
    ↓
ブロック単位で編集
    ↓
ブロック配列の JSON として保存
    ↓
JSON から HTML へレンダリング
    ↓
表示・復元・再編集
```

## 8. JSON データ仕様

### 8.1 トップレベル

```json
{
  "version": "v.0.1",
  "time": 1692547200000,
  "blocks": [
    {
      "id": "block_001",
      "type": "heading",
      "data": {
        "level": 1,
        "text": "タイトル"
      }
    }
  ]
}
```

### 8.2 ブロック共通形式

```json
{
  "id": "block_1234567890",
  "type": "heading",
  "data": {}
}
```

| フィールド | 型 | 説明 |
|---|---|---|
| `id` | string | ブロックの一意識別子 |
| `type` | string | ブロックタイプ |
| `data` | object | ブロック固有データ |

## 13. セキュリティ

### 13.1 XSS 対策

- HTML 出力時にエスケープまたはサニタイズする。
- 危険なタグと属性を除去する。
- イベントハンドラー属性を許可しない。

### 13.2 URL 検証

- `http:` と `https:` を基本許可とする。
- `javascript:` を禁止する。
- 画像、音声、動画の URL は許可スキームを制限する。

### 13.3 JSON 検証

- `blocks` が配列であることを検証する。
- `type` が許可済みブロックタイプであることを検証する。
- `data` の必須フィールドを検証する。
- 不正な値は保存前に拒否する。
